# Source-aware campaign link sheet

Prepared for the existing Photografik preview. **Preview URLs are for testing. Launch URLs are templates to use only after the production release is approved and verified.** No social profile, ad, email campaign, printed QR code or partner website has been changed.

## How to use

- Pick the matching destination and copy its link. Visitors land on that page immediately; recommendations remain optional.
- Use these tags on links coming from outside the site. Keep ordinary internal navigation untagged so it does not replace the original source.
- `intent` sets the starting service suggestion; the visitor can choose another service. `utm_source` names the channel, `utm_medium` groups the channel type, and `utm_campaign` names the campaign.
- Use lowercase campaign slugs; never add a customer name, email, phone number or private brief to tags. The inquiry retains coarse source and campaign. The existing analytics setup can use standard UTMs once production analytics is enabled; preview analytics stays off by default.
- A visit, banner click or booking handoff is not a completed inquiry or appointment. Real inquiry receipt remains a separate launch requirement.
